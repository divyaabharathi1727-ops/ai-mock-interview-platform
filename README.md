# AI Mock Interview Platform

An AI-powered mock interview platform that helps students practice technical and behavioral interviews and receive AI-based feedback.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Spring Boot
- Java
- MySQL
- AI / LLM API

## Features

- User authentication
- Job role selection
- AI-generated interview questions
- Technical and behavioral interviews
- AI-based answer evaluation
- Interview performance analytics
- Responsive design
